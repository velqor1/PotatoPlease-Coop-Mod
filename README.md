# 🥔 Potato Please — Steam Spacewar Co-op Mod

<p align="center">
  <b>Полноценный сетевой кооператив (до 4 игроков) для одиночной игры Potato Please через Steam Spacewar (AppID 480).</b>
</p>

---

## 🌟 Особенности / Features

- 🎮 **Steam Spacewar (AppID 480) P2P Сеть**:
  - Прямое подключение через инфраструктуру Valve Steam.
  - Приглашения друзей через стандартное меню оверлея Steam (`Shift+Tab`).
  - Быстрое подключение по **Lobby ID** через буфер обмена (для тех, у кого отключен оверлей).
  - Поиск открытых смен друзей прямо в главном меню.

- 👨‍🍳 **Уникальные 3D Модели и Роли Игроков**:
  - Напарники видны как полноценные 3D персонажи с процедурной анимацией ходьбы и наклонов головы.
  - 4 уникальных стиля и формы:
    - **Шеф-повар** (белый китель, колпак, усы, королевский синий фартук).
    - **Мастер очистки** (бежевая куртка, красный берет, веснушки, оранжевые перчатки).
    - **Механик пресса** (рабочая форма, жёлтая каска, защитные очки сварщика).
    - **Подмастерье** (фартук ученика, поварская пилотка).
  - Отображение активного инструмента в правой руке (ножи, скребки, аппараты).
  - Чёткие плавающие 3D-таблички с ником и ролью над головой каждого напарника.

- 🥔 **Полная Синхронизация Геймплея**:
  - **Задания и квесты (`QuestManager`)**: Единый прогресс выполнения приказов министерства для всей смены.
  - **Экономика и баланс (`EconomyManager`)**: Общий кошелёк смены и улучшения.
  - **Интерактивные объекты**: Синхронизация очистительных машин, вращения рукояток и дверей бункера.

- 🖥 **Нативный Игровой Интерфейс**:
  - Кнопка **«Кооператив (Steam)»** органично встроена в Главное Меню.
  - Кнопка **«Сетевая смена (Steam)»** доступна в меню паузы (`ESC`).
  - Вызов Сетевого Терминала в любой момент по клавише **`F1`** или **`Ctrl + M`**.
  - Компактный внутриигровой HUD бригады со списком участников в левом верхнем углу экрана.

## 📦 Быстрая Установка (через Установщик)

1. Скачайте архив **`PotatoPlease-Steam-Coop-v1.0.0.zip`** из вкладки [Releases](../../releases).
2. Распакуйте архив в любое место или в папку с игрой.
3. Запустите **`PotatoCoopInstaller.exe`** (или `Install.bat`).
4. Установщик автоматически определит путь к игре и скопирует все необходимые модули.
5. Запустите Steam, затем запустите игру `PotatoPlease.exe`.

---

## 🛠 Ручная Установка

Если вы предпочитаете ручную установку:
1. Скопируйте папку `MelonLoader` в корневую папку игры.
2. Скопируйте `version.dll` и `steam_appid.txt` в корень игры (рядом с `PotatoPlease.exe`).
3. Скопируйте `steam_api64.dll` в `PotatoPlease_Data/Plugins/x86_64/`.
4. Скопируйте файл `PotatoCoop.dll` в папку `Mods/`.

---

## 🎮 Как играть с друзьями

1. **Запустите клиент Steam** на своём ПК.
2. Запустите `PotatoPlease.exe`.
3. В главном меню нажмите кнопку **«Кооператив (Steam)»** (или клавишу **`F1`**).
4. Выберите роль и нажмите **«★ Создать смену (Хост)»**.
5. Нажмите **«✉ Пригласить в Steam»** или **«📋 Скопировать ID лобби»** и отправьте ID другу в Telegram/Discord.
6. Друг запускает игру, жмёт **`F1`** -> **«📥 Вставить ID и войти»**.
7. Нажимайте **«▶ Начать смену всем»** — хорошей совместной смены, товарищи!

## 💻 Сборка из исходников

Требования: [.NET 6 / 8 SDK](https://dotnet.microsoft.com/download).

```bash
# Клонировать репозиторий
git clone https://github.com/<ваш-аккаунт>/PotatoPlease-Coop-Mod.git
cd PotatoPlease-Coop-Mod

# Собрать мод и установщик
dotnet build src/PotatoCoop/PotatoCoop.csproj -c Release
dotnet publish src/PotatoCoopInstaller/PotatoCoopInstaller.csproj -c Release -o dist/Installer
```
